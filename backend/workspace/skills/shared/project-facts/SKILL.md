# 项目事实与底线（共性）

本规范跨岗位生效，优先级高于通用手艺和模式包的创作建议。与项目风格或事实保真冲突时，以本规范为准。

## 事实保真

- 人物、事件、关键道具、对白逐字来自上游；不新增、不删除、不改写事实。
- 下游只引用上游的 ID、编号和文本，不重新定义。
- 缺信息时返回明确的阻塞原因，不编造。

## 风格锁

- 视觉风格只来自项目 `dramas.style`；任何阶段不写画风词，不改写风格。
- 图片提示词由保存工具自动注入风格；文本阶段只写内容。

## 连续性

- 角色外观与服装状态、场景光源、道具状态、时间状态跨镜连续。
- 变化必须有上游依据；状态变化不覆盖基础母版。

## 对白与归属

- 对白逐字保留；说话人、画内/画外归属不换人。
- 分镜、配音、字幕只消费上游归属，不重写。

## 输出契约

- 只输出当前阶段字段；保持上游 ID 与编号；该调用的工具必须实际调用。
- 不输出规划、分析或解释性文本；失败时给结构化原因。
