# 视频提示词手艺（通用）

本规范只写“怎么把分镜段落编译成视频提示词”，不写题材风格；画风由项目风格统一注入。服务商语法差异由服务商包补充，这里只写通用契约。

## 1. 输入与输出边界

- 输入：单个分镜段落的 `description`（含【镜头N】、台词/旁白）、`atmosphere`、`duration`、绑定的场景/角色/道具。
- 输出：该段落的一个 `video_prompt`，只更新这个字段，不重新拆整集、不改其他字段。
- `description` 是唯一内容来源：画面、动作、台词、旁白都来自它；不新增 `description` 之外的台词、动作或人物。
- 一个段落 = 一段 8–15 秒视频；段内可切镜，但不跨场景、不闪回。

## 2. 首行信息头

第一行先交代“谁、在哪”，再进入时间分段：

```text
出场人物：@小明、@小红；场景：@咖啡厅。
0-3秒：...
3-6秒：...
```

- 只列本段落实际出场的人物、绑定的场景；有明确道具时追加 `；道具：@信件`。
- 名字必须与上下文列表完全一致，不缩写、不加符号；`@名字` 会在生成时替换为参考图片标记。
- 信息头独立一行，以句号结尾。

## 3. 时间分段

- 按 3 秒一段，每段单独一行，时间范围连续、无重叠、无空缺。
- 段数 = `duration` ÷ 3 秒，向上取整；各段时间相加等于段落总时长。
- `description` 的每个 `【镜头N】` 映射为 1–2 个连续 3 秒段：顺序一致、不遗漏、不合并、不新增子镜头。
- 台词/旁白从对应 `【镜头N】` 内提取，分配到该子镜头映射的段；3 秒念不完的长台词拆到多段。

## 4. 每段结构

按此顺序组织，可省略无内容的项，但画面/动作必须有：

```text
时间范围 + @场景 + 景别/运镜 + @角色 + 主体动作/表情 + 对白/旁白 + 光源与氛围
```

- 第一段建立空间：场景、机位、人物位置与状态，让观众一眼知道在哪、看谁。
- 切镜后的段开头用“切到/切回”，重新交代景别与主体；切点对齐 `【镜头N】`。
- 每段一个主动作，动词具体可见：走、停、转身、抬头、攥紧、后退、避开视线。
- 情绪转成可见描写：不写“他很伤心/气氛紧张”，写“他低下头、手指攥紧杯沿、呼吸变重”。
- 每段写清光源位置与方向：窗光从哪侧来、路灯在画面上方、屏幕光打在脸上；黑暗场景也要保留可读细节。
- 对白写「角色名说：「台词」」，旁白写「旁白：内容」；无对白可写环境音/动作音。

## 5. 引用与连续性

- `@场景名` / `@角色名` / `@道具名` 必须与上下文列表完全一致。
- 只引用该段落已绑定的场景/角色/道具；每段至少一个 @ 引用锚定画面。
- 角色出场必须 @ 角色；道具被使用、交接、特写或明显可见时 @ 道具。
- 同段落内保持人物位置、视线、屏幕方向连续；不在段内跳轴。
- 段与段之间可以硬切，但空间关系和人物状态必须接得上。

## 6. 禁止事项

- 跨场景切换、闪回、段内换景。
- 引用列表之外的场景/角色/道具名。
- 抽象心理描写、文学化比喻、模型无法执行的参数。
- 新增台词、改变说话人、改变事件结果。
- 写入画风词；风格由项目统一注入。

## 7. 自检

- [ ] 首行信息头只列实际出场的人物/场景/道具
- [ ] 3 秒分段连续，段数匹配 duration
- [ ] 【镜头N】全部映射，顺序一致，没有新增子镜头
- [ ] 每段有可见动作和光源位置
- [ ] 台词逐字来自 description，说话人不变
- [ ] @引用名字与列表完全一致
- [ ] 没有跨场景、闪回、画风词
- [ ] 只调用 `update_storyboard` 更新 `video_prompt`
