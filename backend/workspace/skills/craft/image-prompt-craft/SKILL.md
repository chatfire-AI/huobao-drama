# 生图提示词手艺（通用）

本规范只写“怎么把资产写成生图提示词”，不写题材风格；画风由项目视觉风格统一注入到提示词最前方，本规范禁止写入画风词。输出语言跟随会话语言指令。

## 1. 角色最终提示词

目标：一张可复用的角色设定参考图，作为后续所有角色图片、视频参考的形象锚点。**一致性 > 美观。**

构图固定：

- 左侧：正脸特写——头部与肩部正面近景，五官、发型、肤质清晰，作为脸部辨识锚点。
- 右侧：正面、90 度侧面、背面三张等高全身视图；同一角色，头顶与脚底对齐，间距均匀。
- 特写与三张全身视图必须是同一张脸、同一发型、同一服装。

输出结构：

```text
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰]，
正脸特写与三个视图的脸、发型和服装完全一致，
纯白背景，柔和均匀的光线，电影质感
```

描述顺序：

1. 身份锚点：年龄感、性别感、体态、姿态习惯。
2. 五官：脸型、眼睛、显著特征（疤、痣、眼镜）。
3. 发型：颜色、长度、样式。
4. 服装：款式、颜色、材质、状态（磨损、皱褶、污渍）。
5. 配饰：只写有辨识度的，不堆砌。

禁止：动态姿势、夸张表情、手持道具、与他人同框、身体裁切、文字/水印、重阴影、彩色背景光、背景道具。

保存：`save_character_final_prompt`；prompt 不含风格词。

## 2. 场景最终提示词

目标：一张无人的广角建立镜头，作为该场景所有镜头的背景参考锚点。空间必须读得懂、对得上、可复用。

输出结构：

```text
固定机位广角镜头，清晰的建立镜头，[地点 + 年代质感]，[时间段]，
前景（[前景元素]）、中景（[中景主体空间]）、后景（[后景纵深]）三层分层构图，
出入口（[门/通道的位置与样式]），地面（[地面材质与状态]），墙面（[墙面材质与颜色]），
[主要陈设及其固定相对位置]，
空间结构连续、自洽，
[光源 + 色温 + 明暗对比]，[氛围]，
画面中没有任何人物，空场景，电影质感
```

空间规则：

- 前景：1–2 个框景/遮挡元素，制造纵深。
- 中景：主体空间与核心陈设。
- 后景：空间延伸（墙、窗、走廊、城市轮廓）。
- 出入口：门、楼梯、通道的位置与样式必须明确，供后续调度人物进出。
- 地面与墙面：材质、颜色、状态具体化。
- 主要陈设：2–4 个，写清左右/远近的固定相对位置，不只罗列物品名。
- 光源：方向、色温、明暗对比具体化；这是场景的固有光源基准。

禁止：任何人物、文字/招牌可读文字、水印、动态模糊、运动中的物体、只罗列陈设不写相对位置。

保存：`save_scene_final_prompt`；prompt 不含风格词。

## 3. 道具最终提示词

目标：一张白底单品图，标准产品摄影视角，供视频特写引用，保证道具外观跨段落一致。

三条硬性要求：

1. 比例准确：不夸张、不变形、不风格化拉伸。
2. 边缘完整：整体入镜，四周留白，不被裁切。
3. 背景不承载叙事：纯白背景只是衬底，不带场景感、情节暗示或装饰。

输出结构：

```text
单品产品图，标准产品摄影视角，[道具名 + 材质/颜色/形状/大小 + 新旧程度与磨损细节]，
物品各部分比例准确，孤立放置在纯白背景上，居中完整入镜，边缘完整无裁切，
背景纯净不承载任何叙事内容，无其他物品、无人物、无场景，
柔和均匀的影棚光，轻淡阴影，高细节
```

规则：

- 以 `name` + `description` 为核心，材质、颜色、形状、大小、新旧、磨损逐项落地。
- 视角：微俯视 3/4 视角；扁平道具（纸张、证件、照片）用正俯视平铺。
- 只写物品本身，不写剧情、角色、用途。
- 不用“电影质感”类词；道具图是产品图，不是剧照。

禁止：手部持握、人物、其他物品、场景环境、包装/底座/展示架（除非是道具本体）、水印、环境反光、彩色光、夸张透视、比例失真、边缘裁切。

保存：`save_prop_final_prompt`；prompt 不含风格词。

## 4. 通用自检

- [ ] 角色图：左特写 + 右三视图，同一张脸/发型/服装
- [ ] 角色图：全身完整、A 字站姿、纯白背景、无道具
- [ ] 场景图：无人、三层空间、出入口明确、陈设位置自洽
- [ ] 场景图：光源方向与场景资产一致
- [ ] 道具图：白底单品、比例准确、边缘完整、无叙事背景
- [ ] 所有提示词不含画风词，风格由工具注入
- [ ] 输出语言与会话语言指令一致
- [ ] 已调用对应保存工具，不是只在回复里给提示词
