# 导演分镜手艺（通用）

本规范只写“怎么拆、怎么拍”，不写题材风格；题材差异由当前模式的模式包补充。一个分镜 = 一个分镜段落 = 一个视频生成任务：8–15 秒，内部 2–4 个子镜头，子镜头可切镜但不跨场景。

## 0. 先定边界

- 节拍边界强制切段：地点转移、规则揭示、情绪爆发、反转、时间跳跃都是段边界。
- 同一因果链（铺垫—发生—反应）不要切散到不同段落。
- 目标总时长 = 剧本字数 ÷ 500 字/分钟；段落数 ≈ 总时长 ÷ 12 秒，允许 ±20%。
- 一个段落只发生在一个场景内，不闪回、不跨场景。

## 1. 覆盖：先保证故事讲清楚

- 每个叙事节拍至少有一个镜头承载；没有镜头承载的节拍视为漏拍。
- 事件和反应都要覆盖：谁做了什么（事件），谁看到了、怎么反应（反应）；关键反应不能只在台词里交代。
- 保持轴线：同一场景内人物关系线不跳轴；视线方向、屏幕方向、出入画方向连续。
- 每个镜头必须有功能：推进信息、建立空间、展示反应、制造转折或完成动作；没有功能的镜头删除。
- 台词必须落在具体镜头里，不能只在段落描述中“说过”。

## 2. 调度与表演：人物怎么动

- 用场景锚点组织动作：人物从哪个出入口进出、站在哪个陈设旁、和谁保持什么距离。
- 动作使用可见动词：走、停、转身、坐下、伸手、攥紧、后退、避开视线；不写“他很生气”这类抽象状态。
- 每个子镜头至少一个表演节拍：动作、反应、停顿或视线变化。
- 表演转折要落在动作上：态度变化用靠近/后退、抬眼/低头、放松/绷紧表现。
- 保留原剧本事件，不新增人物、不改变事件结果。

## 3. 景别与构图：观众看什么

- 按观看重点选择景别：环境关系用全景，对话和动作关系中景，情绪与关键细节近景/特写。
- 构图必须写清必须看到的主体、道具和空间关系；不只写“近景”不写画面内容。
- 给动作留空间：人物运动方向前方留空；对话留视线空间；头顶不切、下巴不切。
- 段落内景别变化要服务信息：先建立空间，再进入关系，最后落到细节或反应。
- 关键道具第一次出现要有可识别的构图，不要只当背景。

## 4. 运镜与焦点：摄影机怎么动

- 写清相机起止状态：起幅在哪、落幅在哪、中间怎么移动；只写“跟拍”不算完成。
- 运动必须有触发点：人物起身、转身、开门、视线转移、情绪爆发；没有依据的推拉摇移删除。
- 焦点转移要有目标：从谁转到谁、从人脸转到道具、从前景转到后景；写清转移时机。
- 固定镜头是默认选项；一个段落内运镜方式不要频繁切换。

## 5. 用光：光从哪里来

- 承接场景资产的固有光源：窗光、路灯、顶灯、火光、屏幕光；不凭空发明主光方向。
- 写清本镜的主光方向、明暗重点和需要保留的细节；暗部不要吞掉关键表情或道具。
- 同场景跨段落保持光源方向、色温和明暗关系连续。
- 需要改变场景光基准时，回给美术/场景资产，不在分镜里硬改。

## 6. 时长与接点：一段多长、在哪里切

- 段落时长 8–15 秒，整数秒；过渡段 8–10 秒，叙事段 10–15 秒，爆点段 12–15 秒。
- 台词时长下限：段落时长 ≥ 段内台词与旁白总字数 ÷ 4.5 字/秒 + 2 秒表演余量；装不下就拆到下一段。
- 切点对齐子镜头：动作切换点、视角切换点、对象切换点；不在一个动作中间硬切。
- 首段建立空间：场景、机位、人物位置与状态；末段落到结果、反应或钩子。
- 段落之间可以硬切，但屏幕方向和空间关系要连续。

## 7. 输出字段

- `shot_number`：连续递增；`title`：3–5 字概括。
- `scene_id` / `character_ids` / `prop_ids`：只从上下文列表选择，不凭空造 ID。
- `shot_type` / `angle` / `movement`：主导景别、机位角度、运镜方式；多景别写组合。
- `description`：按【镜头1】【镜头2】逐子镜头写观众看到和听到的内容；画面在前，台词写在对应子镜头内。
- `result`：段落结尾的即时后果；`atmosphere`：光线与氛围；`duration`：整数秒。
- `video_prompt`：本段落的分镜初稿，必须含首行信息头、按 3 秒分段、@场景/@角色/@道具引用、不新增台词；最终语法由提示词阶段接手。
- `bgm_prompt` / `sound_effect`：简洁具体，不写只有“紧张”“悲伤”的空泛词。

## 8. 自检

- [ ] 每个节拍都有镜头覆盖，没有漏拍
- [ ] 事件和关键反应都拍到了
- [ ] 轴线、视线、屏幕方向连续
- [ ] 每个镜头都有功能，没有废镜
- [ ] 调度有场景锚点，动作用可见动词
- [ ] 景别选择有观看重点，构图写清主体/道具/空间
- [ ] 运镜有触发点，焦点转移有目标
- [ ] 用光承接场景固有光源
- [ ] 时长整数且满足台词下限
- [ ] `video_prompt` 初稿满足首行信息头、3 秒分段、@引用
