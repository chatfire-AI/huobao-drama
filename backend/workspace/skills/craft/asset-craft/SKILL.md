# 美术资产手艺（通用）

本规范只写“资产怎么建、怎么复用”，不写题材风格；题材差异由当前模式的模式包补充。目标不是多提取，而是让下游角色、场景、道具跨镜、跨集稳定可复用。

## 1. 角色母版

每个角色输出一个可复用的母版，字段与 `save_dedup_characters` 一一对应：

- `name`（必填）：角色全名
- `role`：主角 / 配角 / 龙套
- `appearance`：样貌锚点，300–500 字——年龄感、性别感、体态、脸型、眼睛、发型、显著特征（疤、痣、眼镜）。性格不单独写，转成外在气质与神态（“冷峻”写成“眼神冷峻、表情克制、少有笑意”）
- `styling`：妆造锚点——发型、服装款式/颜色/材质、妆面、配饰
- `description`：背景与人物关系，只写会影响表演和造型的部分

规则：

- 识别锚点优先：先写最有辨识度的脸、发型、体型、服装轮廓，再补细节。
- 母版是“基础版”；剧情需要的受伤、换装、淋雨、年龄变化，写成“状态版”，不要覆盖基础版。
- 同一角色跨集复用同一个母版；只追加状态变化，不重新发明外观。
- 不写镜头、光线、构图；这些属于分镜阶段。

## 2. 场景锚点

每个场景输出一个可复用的空间锚点，字段与 `save_dedup_scenes` 一一对应：

- `location`（必填）：具体场所名
- `time`：时间段（清晨/白天/黄昏/深夜）；同地点不同时段视为新场景
- `prompt`：空间描述——前景/中景/后景、出入口、地面、墙面、2–4 个核心陈设及固定相对位置；纯环境，不含人物
- `lighting`：固有光源——光源位置、方向、色温、明暗对比（窗光、路灯、顶灯、火光）

规则：

- 空间必须读得懂、对得上：人物从哪里进出、核心陈设在什么位置，后续镜头才能调度。
- 固有光源属于场景资产；分镜只能承接和局部调整，不能凭空换主光方向。
- 场景参考图必须是空镜；人物、手部、动态物体不进入场景锚点。
- 年代、地域、阶层质感写进场景，但不要写具体画风词；画风由项目风格统一注入。

## 3. 道具账本

道具是高成本资产，**宁可少提，不要多提**。一集通常 0–3 个，超过 3 个按剧情重要性只保留前 3 个。

必须同时满足：

1. 直接推动剧情：出现、交接、损坏或发现会引发情节转折。
2. 值得单独生成图片：后续会特写或反复出现，需要固定外观。

判定三问，任一为“否”即放弃：

- 删掉它剧情是否依然成立？成立则不提取。
- 它只是随手使用的日常物品（手机、筷子、水杯、香烟、雨伞）吗？是则不提取。
- 它是场景陈设的一部分（桌椅、灯具、门窗、挂画、餐具）吗？是则不提取。

字段与 `save_dedup_props` 一一对应：

- `name`（必填）
- `type`：日常 / 武器 / 交通 / 装饰 / 文件等
- `description`：只写物品物理外观——材质、颜色、形状、大小、新旧、磨损；不写剧情用途，不写与角色/事件的关联

规则：

- 道具账本记录“基础外观 + 状态变化”（如“信纸：干燥 → 被雨水打湿”）；状态变化不能覆盖基础外观。
- 道具必须符合年代与世界观：科技产品、服饰、建筑、交通工具不能穿越。
- 没有符合条件的道具就传空数组，不要凑数。

## 4. 当前集与去重

- 只补齐当前集真实涉及的角色、场景、道具，不重扫整个项目。
- 项目中已存在但当前集未关联的，复用并关联，不重复创建。
- 角色/道具按名称精确匹配；场景按【地点 + 时间段】精确匹配。
- 近名去重：名称带括号定位或别名时，按括号前主体比较（“林小雨（主角）”与“林小雨”视为同一角色/道具）；使用工具返回的 `normalized_name` / `normalized_location` 判断。

## 5. 工具步骤

1. `read_script_for_extraction` 读取当前集剧本。
2. `read_existing_characters` / `read_existing_scenes` / `read_existing_props` 读取已有资产与当前集关联。
3. 按角色母版、场景锚点、道具账本三类提取。
4. 依次调用 `save_dedup_characters`、`save_dedup_scenes`、`save_dedup_props` 保存并关联当前集。

## 6. 自检

- [ ] 每个有台词或重要动作的角色都有母版
- [ ] 角色识别锚点完整，性格已转成外在描写
- [ ] 每个场景有出入口、核心陈设位置和固有光源
- [ ] 道具不超过 3 个，且每个都推动剧情
- [ ] 道具只有物理外观，没有剧情用途
- [ ] 已复用已有资产，没有重复创建
- [ ] 没有写入镜头语言或画风词
