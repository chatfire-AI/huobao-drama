# 编剧手艺（通用）

本规范只写“怎么写剧本”，不写题材风格；题材差异由当前模式的模式包补充。不写景别、角度、运镜，这些属于分镜阶段。

## 1. 场戏结构

每场必须回答四件事：

- 目标：这场谁想要什么？
- 阻碍：什么力量阻止他？
- 转折：这场结束时，信息、关系或处境发生了什么变化？
- 可拍动作：人物做了什么可见的动作来推进？

规则：

- 事件要有因果链：前一场的结果成为后一场的原因，不靠巧合跳转。
- 每场 30–60 秒；没有变化的场删除或合并。
- 场景头只写时间、地点、内外景，不写情绪和镜头。
- 心理描写必须转成表情、动作、对白或画外音，不能直接写“他心里想”。
- 不新增源文本没有的人物、事件、关键道具；需要补桥段时，只补连接动作，不补新事实。

## 2. 对白与发声归属

- 对白逐字保真：保留源文本的台词内容、语气词、停顿和称呼；只做必要的口语化，不改变信息。
- 每句对白必须有明确说话人；多人同时说话要拆行。
- 标明画内/画外：画外音、电话、旁白、回忆中的声音单独标注，不能和现场对白混在一起。
- 说话人不能在下游被换人；分镜和配音只消费这里的归属。
- 台词要有潜台词：说出口的和真实意图有落差；避免解释性台词，避免角色复述观众已经看到的事。
- 每 3 句至少推进一次信息、关系或情绪；纯寒暄删除。

## 3. 节奏与钩子

- 开场前 3 秒：一个异常、压力、冲突或强信息，不用背景介绍开场。
- 每 30–45 秒至少一次信息或关系变化；每场至少一个小转折。
- 集末钩子：新信息、新威胁、新选择或未解决的问题；不用“欲知后事”式旁白。
- 长段叙述拆成多个短场景；过场只保留必要信息。

## 4. 可拍性

- 只写演员能完成的动作：走、停、转身、低头、攥手、呼吸变化、拿起或放下。
- 不写“镜头推近”“特写”“闪回”等镜头语言；需要强调时，用人物动作和物件细节。
- 每个场景至少一个可见的表演节拍；没有可见动作的场景视为不可拍。
- 场景编号连续递增；时间段具体到清晨、黄昏、深夜，不写笼统的“白天”。

## 5. 输出格式

```text
## S01 | 内景 · 咖啡厅 | 黄昏

动作描写自然段，不包含镜头语言。

角色名：（状态/表情）台词内容
```

- 场景头：`## S编号 | 内景/外景 · 地点 | 时间段`
- 对白：`角色名：（状态/表情）台词内容`
- 动作：自然段；一段只写一个连续动作单元。
- 格式化后总字数相对原文增加约 20–30%，增量来自场景头和对白格式化，不靠扩写。

## 6. 改写步骤

1. 调用 `read_episode_script` 读取原文。
2. 标出每场的目标、阻碍、转折和可拍动作；缺哪项就补哪项。
3. 标出每句对白的说话人和画内外属性；旁白、电话、回忆单独归类。
4. 按格式改写；保留源事实和台词，不新增人物和关键事件。
5. 调用 `save_script` 保存完整剧本；不要只返回说明。

## 7. 自检

- [ ] 每场都有目标、阻碍、转折
- [ ] 事件有因果，不靠巧合
- [ ] 每句对白有说话人，画内外清楚
- [ ] 台词逐字保真，无解释性台词
- [ ] 前 3 秒有钩子，集末有钩子
- [ ] 没有镜头语言，没有不可拍的心理描写
- [ ] 场景编号连续，时间段具体
- [ ] 已实际调用 `save_script`
