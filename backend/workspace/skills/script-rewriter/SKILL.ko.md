# 대본 리라이팅 가이드

## 리라이팅 원칙

1. **핵심 줄거리 보존**: 메인 스토리와 캐릭터 관계를 바꾸지 않습니다
2. **화면감 강화**: 서술적 문장을 시각화 가능한 장면 묘사로 전환합니다
3. **대화 중심**: 대사로 줄거리를 추진하고 내레이션을 줄입니다
4. **리듬 조절**: 각 장면을 30-60초로 조절해 숏폼 영상에 맞춥니다
5. **카메라 언어 금지**: 화면 크기, 앵글, 카메라 무빙을 다루지 않습니다 — 이는 스토리보드 분할 단계에 속합니다

## 포맷된 대본 형식

```
## S01 | 실내 · 카페 | 황혼

황혼의 빛이 통유리창을 통해 카페 안으로 쏟아지고, 바 위의 커피잔에서 김이 모락모락 오른다.

小明은 홀로 구석 부스에 앉아 휴대폰을 내려다보며, 표정이 다소 불안하다.

문벨이 울리고 小红이 문을 밀고 들어온다. 그녀는 小明을 보고 미소 지으며 다가간다.

小红:(미소) 오래 기다렸어?
小明:(고개를 들며) 아니, 나도 방금 왔어.
```

### 형식 규칙

- `## S번호 | 실내/실외 · 장소 | 시간대` — 장면 헤더
- 동작 묘사는 자연스러운 문단 — 어떤 카메라 언어도 포함하지 않음
- `캐릭터명:(상태/표정) 대사 내용` — 대사 형식

### 내용량 참고

포맷된 대본은 원본 내용 대비 약 20-30% 증가하며, 주된 증가분은 장면 헤더 마커와 대사 포맷팅이지 내용 확장이 아닙니다.

## 리라이팅 절차

1. 먼저 `read_episode_script` 를 호출해 원본 내용을 읽습니다
2. 내용 구조를 분석합니다(대화, 서술, 심리 묘사의 비율)
3. 이미 읽은 원문을 바탕으로 직접 리라이팅하며 원문을 다시 읽지 않습니다
4. 리라이팅 결과를 확인해 포맷된 대본 형식에 부합하는지 검토합니다
5. `save_script` 를 호출해 최종 결과를 저장합니다

## 주의 사항

- 심리 묘사는 캐릭터의 표정/동작 또는 화면 밖 목소리로 전환할 수 있습니다
- 긴 서술 문단은 여러 짧은 장면으로 나눕니다
- 각 장면에 명확한 감정 전환점이 있도록 합니다
- 캐릭터의 말투 스타일 일관성을 유지합니다
- 장면 번호는 연속 증가(S01, S02, S03...)
- 시간대는 구체적으로 씁니다(황혼, 심야, 이른 아침). "낮"처럼 대략적으로 쓰지 마세요
